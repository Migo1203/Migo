# 从 Migo 到 Beedog：品牌自述与设计输入

日期：2026-11-09。下述个人经历与期待由本人提供，设计解释由 AI 整理，未形成视觉定稿。

## 1. 昵称与角色的个人联系｜本人说明

> 我的昵称叫 Migo，来自中文谐音“蜜蜂小狗／蜜狗”。我的脸圆圆的，朋友说我长得很像那个脸被蜜蜂蜇后肿起来的小狗表情包，于是给我取了这个名字。

以上为按原意整理的本人自述，非逐字引文。Beedog 的灵感与本人外貌、朋友间的称呼及相处经历有关。本人所说的网络表情包流行原因、原始图片和具体出处，本轮没有外部核实。

Migo 是本人和主品牌；Beedog 是计划发展的原创角色。昵称的个人联系已经说明，角色的独立原创造型仍需设计，二者不能混为已经完成的 IP 资产。原照片不直接复制，角色也不必反复表现被蜇伤或痛苦。

## 2. 我的性格不只是一层外观｜本人自述

本人认同好奇、友好、偶尔笨拙，也认为自己内心世界丰富，具有精神内核和内涵，喜欢尝试与挑战新事物，尤其对 AI 工具和 AIGC 感兴趣。本人 MBTI 为 INTP，档案只保存这一自我描述，不从类型标签生成完整人格或职业结论。

“内在丰富”“认真细致”“艺术敏感”可以先作为本人想观察和表达的特质；以后通过真实经历、想法与选择使它们具体，不为了品牌故事编造事件。

## 3. 希望品牌传达什么｜已明确的偏好

| 希望表达 | 后续需要具体化的问题 |
| --- | --- |
| 年轻、新潮 | 我喜欢哪些新鲜表达，为什么？是视觉形式、观察角度，还是工作方法？ |
| 独立内核、有内涵 | 我真正认同什么，在哪些判断中愿意坚持，什么情况下会改变主意？ |
| 想法丰富、敢于创新 | 可以用哪些本人提出的概念与实际实验体现，而不是只做风格变化？ |
| 认真、细致 | 哪些取舍与修正说明我在意结果？哪里适合停止打磨？ |
| 对艺术敏感 | 哪些具体作品、媒介或细节引起我的感受，如何说明？ |
| 独立性、差异化 | 与参考拉开距离的理由是什么？目标对象是否真的能感知这种区别？ |

这些问题用于后续认识与创作，不要求现在全部作答。不是已核实的优势、用户评价或市场结论。

## 4. 可爱与反差的边界

**本人最新意愿：** 不希望只是可爱，甚至可以不可爱，更希望表现认真细致；风格尚未确定。

**历史建议：** “外表呆萌，内在充满探索欲”，由 Beedog 承载疑惑、兴奋、观察和创作陪伴。

**当前处理：** 保留“外在表达与内在思考可以存在层次”的研究方向，不把呆萌外形列为必须。不要把丰富内心等同于深色、复杂纹样，也不要把新潮等同于荧光色、故障特效或某种流行风格。角色可以有独立叙事价值，具体视觉与人格关系需要方案验证。

## 5. 可延续的基础与待选择的候选

延续 Migo 为主品牌、Beedog 为角色、“好奇探索，认真设计”的基础。以个人品牌 IP 作为希望发展的创意代表作，同时继续求职与现有作品完善。

字标、轮廓、脸颊比例、角色身体、表情、配色、字体和媒介均未定。历史稿的蜂蜜黄／深炭黑／暖白、现代简洁温暖等只是候选。名字含“蜜”不必然要求黄色或蜜蜂配件。

## 6. 下一步建议｜尚未执行

先以一两个真实经历具体说明“我为什么这样想、这样选”，再整理参考与概念依据；之后比较视觉方向。每个方案应说明体现了哪项个人特质、舍弃了什么，以及本人和 AI 各自的贡献。不因要做品牌而提前规定复杂世界观、周边或庞大交付清单。

个人品牌可以服务求职，也可以承载长期自我表达；眼下求职优先不应抹去这个项目的个人意义。
