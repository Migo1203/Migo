## 怎样记录

- **本人自述：** 我提供的经历、感受和想法；不冒充外部独立核验。
- **项目证据：** 实际作品、过程、文件与反馈，注明查看范围。
- **目标与偏好：** 我想做什么、想成为怎样的人，不自动成为已具备能力。
- **AI 建议／待验证：** 可继续讨论的解释，需要真实情境或证据支持。

重要认识变化保留日期和原因；不要求每次都形成宣传文案。MBTI 只记录为自我描述，不据此推导能力或完整人格。
