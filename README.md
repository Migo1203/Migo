## 怎样记录

- **本人自述：** 我提供的经历、感受和想法；涉及履历细节时不冒充外部独立核验。
- **项目证据：** 实际作品、源文件、过程和版本记录；注明看过的范围。
- **目标与偏好：** 我想成为谁、希望品牌如何表达；不会自动成为已具备的能力。
- **AI 建议／待验证：** 保留为可讨论解释，需要实际经历、作品或反馈支持。

新信息优先修正当前档案，重要变化另记日期与原因，旧版本保留。MBTI 只记录为自我描述，不据此推导能力、性格全貌或职业适合度。
